type: content
notes: |
  Reference layout for the most common content slide: a growable block that
  fills the remaining height, with a SummaryBanner as its sibling underneath.

  Nothing here sets a margin by hand. A [data-growable] block consumes every
  remaining pixel and has no margins of its own, so the engine adds the gap
  above the banner (and below an unstyled heading) automatically. If you find
  yourself writing style={{ marginTop: ... }} on a SummaryBanner, the layout is
  fighting the engine — remove it.

  The left column also shows a Markdown image inside a flex box. The engine
  unwraps it out of its paragraph and caps it at 100% of the box, so it can
  never spill past the slide edge no matter how tall the source file is.
---
